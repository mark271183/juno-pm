## Goal

Triage Slack Customer support tickets, Product/customer discovery interviews transcripts daily and document top 3 highest priority customer problems to solve based on the strategic pillars.

**Primary actor:** Agent + Human-in-the-loop

## Trigger

New messages on slack channel #customer support tickets and new product discovery interview transcripts.

## Steps & tools

**Pattern:** ReAct (single-agent reason-act-observe loop)

| Step | Action | Tool / model | Guardrail |
|---|---|---|---|
| 1 | Read slack thread + product/customer discovery interview transcript. | slack.read_thread(id), read-only | Agent can READ Slack #Customer support tickets, Product/customer discovery interviews transcript + Strategy KB. Agent can WRITE to #confluence. Agent CANNOT edit or communicate on slack with stakeholders or get into an argument on conversation. |
| 2 | RAG retrieval over the RocketShip Strategy One-Pager (M3 KB), top-K = 6. | corpus.retrieve(query, k=6), read-only |  |
| 3 | Refer to strategic pillars; emit P0-P3 with rationale. | confluence, write-only |  |
| 4 | Draft summary card (transcript quote + strategic citation). | slack.post(channel, payload), write, restricted to #pm-slack |  |
| 5 | Post to confluence page dedicated for customer improvement priortisation OR route to PM review based on confidence threshold. | _ |  |

**Schemas**

- corpus.retrieve → {chunks:[{text,source,pillar,score}]}.
- confluence page write only

**Memory (in or out of scope)**

- **Episodic:** In-scope, tool results, retrieved chunks, intermediate scores. Lifetime: end of run.
- **Semantic:** In-scope, RocketShip strategic pillar + Juno system prompt + PM preferences. Lifetime: indefinite, refreshed weekly. Out of scope, do NOT persist customer-specific contracts or PII.
- **Working:** In-scope, current slack thread, product discovery transcript, current confidence score. Held in working context only.
- **External:** Slack thread API (read), RocketShip Strategy KB (read), Confluence API(write)

## Human-in-the-loop

PM review recommendation on slack daily 8:00 am : PM has a 5-min review window before the agent auto-posts to confluence document for all stakeholders visibility.

## Success & failure

- **Done when:** - Success: top-3 customer improvement documented on dedicated confluence document.
- Failure: > 2 tool errors in a run → log + abort.
- Escalation: confidence < 70% → hand to PM.
- Timeout: 90s wall clock → abort with partial output.
- **Fails safe when:** Agent can READ Slack #Customer support tickets, Product/customer discovery interviews transcript + Strategy KB. Agent can WRITE to #confluence. Agent CANNOT edit or communicate on slack with stakeholders or get into an argument on conversation.
